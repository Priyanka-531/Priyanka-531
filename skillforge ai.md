# SkillForge AI

> **Tagline:** Forge Your Skills. Build Your Future.

SkillForge AI is an AI-powered Career Intelligence and Skill Development Platform for students and early-career developers.

---

## Project Architecture & Tech Stack

* **Frontend:** React, TypeScript, Vite, Tailwind CSS, React Router, Axios, Lucide React
* **Backend:** Python, FastAPI, SQLAlchemy, PostgreSQL, Pydantic Settings, PyJWT, Passlib, Bcrypt

---

## Getting Started (Day 1 - Auth Foundation)

### Backend Setup
```bash
cd backend
python -m venv venv
# On Windows PowerShell:
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn app.main:app --reload
```

### Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
